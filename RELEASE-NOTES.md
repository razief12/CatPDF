# CatPDF 4.4.2 experimental conversion build
Based on local 4.4.1. New coordinate-based PDF extraction, editable DOCX tables, numeric XLSX cells, HTML and Markdown tables; approximate Word and Excel table rendering to PDF. Existing PowerPoint, text and image paths retained. No new external dependencies. Limitations: heuristic columns, no reliable merged cells, PDF images, Office images, original styles, formulas or exact print layout. Scanned PDFs require OCR. Office PDF output is rasterized. Mixed page sizes use first page dimensions in DOCX. Syntax checked; browser end-to-end and regression testing pending. No full security audit. Existing archive limits retained; HTML and XML output escaped. Do not treat as production verified.
